# 公开文档维护导航

本目录汇总公开仓库中可核对的交付状态、技术入口与范围决定。它是派生导航；正式需求、批准决定及工程验收仍由各自负责人维护。

- [公开状态](public-status.md)：来源时间、工程与文档基线、已合并与待验范围。
- [技术导航](technical-index.md)：当前已发布实现的模块与接口入口。
- [批准决定索引](approved-decisions.md)：已公开范围及保留边界。
- [已知问题与下一步](known-issues-and-next.md)：有公开依据的限制与未闭合事项。
- [同步约定](sync-contract.md)：来源、写者、检查、回读与失败处理。

阅读状态时先核对[来源快照](public-status.md#来源快照)。规划中的能力、未合并开发及旧版本测试结果均不能据此视为当前软件通过。本文档维护本身不新增工程交付事件。

当前快照将已合并实现、同 SHA CI 与正式交付闭环分列；批次临近收尾时，按同一正式事件合并派生同步，不用零散状态更新重复计数。

已发布内容包含 B31 档案背景包、B32 冲突信息下的有界行动薄片、B33 综合现场行动链及 K-A 文本知识采集包；它不代表完整第三阶段。界面改进和 CI 维护分别说明。根 README 的公开旧说明与本目录快照分开核对，不据维护计数推断玩法或完整产品验收。
