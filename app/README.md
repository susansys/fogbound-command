# 玄枢行动工程演练前端

本批新增独立的 `B21-CORRIDOR-01` 演练与 schema7 存档，原有 Move、Record 和任务更新演练保留各自的定义与 schema4/5/6。这里使用虚构地图、消息和规则数值。

在开始页选择走廊演练。默认指挥模式持续推进逻辑时间，阅读资料和编辑路线不暂停；暂停与恢复均须由 Game 确认。研究模式可用于逐步查看消息边界。

选择 R 后可拟定路线，通过地图单击或坐标表格加入折点，预览后再显式确认下达。预览只使用公开依据；已下达计划不表示队伍已接令或已经抵达。总部地图保留最后收到的位置，接令回执没有新定位，抵达定位须等待原报告实际递交。范围目录没有位置的条目保持文字可读，不生成地图中心。

保存包含已提交的活动、连续进度、消息与账务；未下达草案不属于存档。原浏览器 profile、同源恢复会接手同一局并保持暂停，不补关闭期间的墙钟时间。地图显示使用独立存档与读回确认，显示关联版本不能替代 Game 来源与恢复提交版本。

行动复盘只显示所选时刻已具备的依据，历史不能下达、继续或保存。返回当前行动会重新读取当前视图。以相同条件重开会建立新 run，保留随机流来源与只读父局；未确认的重开请求须沿原操作核查，不能盲目再建一局。

现有验证入口为 `npm test`、`npm run typecheck`、`npm run lint`、`npm run browser`。实际运行环境、候选制品和验证边界以 `VERIFICATION.md` 及各批证据为准。本地通过、远端 CI、PR 合并和 main 验收分别记录。工程样例不代表完整第一可玩、原244AT、正式玩家体验或现实军事拟真验收。
